# FreeCM command validator

The MIT-licensed command manifest validator and JSONC helpers are copied from
BCR2000Dev's FreeCM 0.1.156 snapshot. `UPSTREAM.json` records the FreeCM revision,
original hashes and namespace changes; `LICENSE` preserves its license notice.
No FreeCM checkout, Python installation, dependency locks or runtime integration
is required. Application build/run/package does not import these helpers.

The local environment and version helpers in `configs/build_environment.py` and
`configs/app_build.py` follow BCR2000Dev's local build conventions.
